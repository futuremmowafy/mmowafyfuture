# نظام إدارة شركة فيوتشر إير (Future Air ERP) 🌬️

نظام ERP مبسط ومؤمن بالكامل يعمل من خلال **بوت تليجرام** باللغة العربية، مربوط بقاعدة بيانات **Supabase** ومصمم للاستضافة كـ Serverless على منصة **Vercel**.

## 🚀 المميزات الرئيسية
1. **أمان كامل:** البوت مؤمن ومقيد للدخول فقط لـ (صاحب الشركة والابن) عبر معرفات الشات تليجرام (Chat IDs). أي مستخدم غريب يتم حظره تلقائياً.
2. **إدارة المخازن وحركة الأجهزة:**
   - [إذن استلام جهاز جديد]: (ماركة التكييف، القدرة بالحصان، السيريال نمبر، المورد، التكلفة) لزيادة المخزون وتسجيل الدين في حساب المورد.
   - [إذن صرف للفني]: تحديد الفني المستلم والجهاز، وتسجيل بيانات العميل (الاسم، الهاتف، العنوان، السعر، والمقدم) ليتحول الجهاز إلى حالة "قيد التركيب عهدة مع الفني".
3. **أرشفة العقود ومحاضر التركيب:**
   - [توثيق عقد ومحضر]: أرشفة صور الورق والعقود الموقعة يدوياً، وحفظها بسحابة التخزين (Storage) ليتغير حالة الجهاز لـ "تم التركيب بنجاح وتوثيق الورق".
4. **الحسابات والديون:**
   - كشف حساب الموردين ومعرفة المبالغ المتبقية لهم مع إمكانية تسجيل الدفعات وعرض كشف حساب.
   - كشف حساب العملاء والأقساط المستحقة وتسجيل التحصيلات.
   - الخزنة وحركة اليومية (رصيد الخزنة الفعلي، وتسجيل إيرادات ومصروفات يدوية).
5. **الموارد البشرية والرواتب:**
   - تسجيل حضور وغياب وتأخير الفنيين يومياً.
   - حساب صافي الرواتب الشهرية للفنيين تلقائياً بناءً على الغيابات والتأخيرات المسجلة.

---

## 🛠️ هيكل المشروع
- `supabase_schema.sql` : كود إنشاء الجداول والفهارس في قاعدة البيانات.
- `api/webhook.js` : نقطة الدخول (Serverless Function) الخاصة بـ Vercel لاستقبال تحديثات البوت وتفعيل الـ Webhook.
- `lib/` :
  - `bot.js` : إعداد البوت والتحقق من صلاحيات الدخول.
  - `handlers.js` : جميع القوائم التفاعلية والمنطق البرمجي للبوت.
  - `supabase.js` : إعداد الاتصال بقاعدة بيانات Supabase.
  - `sessions.js` : نظام حفظ حالة المحادثة المؤقتة في قاعدة البيانات (Session Store).
- `scripts/` :
  - `local_test.js` : تشغيل البوت محلياً (بدون ويب-هوك) للتجربة والتطوير السريع.
  - `set_webhook.js` : سكربت لربط البوت بعنوان الويب-هوك يدوياً.

## ⚙️ إعداد وتشغيل المشروع

### 1. إعداد قاعدة البيانات (Supabase)
1. افتح مشروعك في [Supabase Console](https://supabase.com).
2. اذهب إلى **SQL Editor** ثم انشئ استعلاماً جديداً (New Query).
3. انسخ محتوى الملف `supabase_schema.sql` الموجود بالمشروع، ثم اضغط **Run**.
4. سيتم إنشاء جميع الجداول اللازمة والفهارس فوراً.

### 2. التشغيل والتجربة محلياً (Local Development)
لتجربة البوت والتأكد من عمله قبل الرفع لـ Vercel:
1. تأكد من تعديل البيانات في ملف `.env` (لقد قمنا بكتابة الرموز الخاصة بك وبقاعدة البيانات مسبقاً).
2. قم بتشغيل الأمر التالي في سطر الأوامر لتشغيل البوت بنظام التلقي (Polling):
   ```bash
   node scripts/local_test.js
   ```
3. افتح بوت التليجرام الخاص بك [@futureairprobot](t.me/futureairprobot) واكتب `/start` وابدأ التجربة!

### 3. الرفع والاستضافة على Vercel
1. قم برفع مجلد المشروع إلى مستودع **GitHub** خاص بك.
2. اربط المستودع بمنصة **Vercel** لإنشاء مشروع جديد.
3. قم بإضافة متغيرات البيئة (Environment Variables) التالية في إعدادات Vercel:
   - `TELEGRAM_BOT_TOKEN`
   - `SUPABASE_URL`
   - `SUPABASE_SERVICE_ROLE_KEY`
   - `AUTHORIZED_USERS`
4. بعد اكتمال البناء والرفع (Deployment)، ستحصل على رابط للمشروع (مثال: `https://futureair-erp.vercel.app`).
5. لتفعيل الـ Webhook وربط البوت بالاستضافة، قم بزيارة الرابط التالي في المتصفح:
   `https://futureair-erp.vercel.app/api/webhook?setWebhook=true`
   أو قم بتشغيله من خلال السطر البرمجي:
   ```bash
   node scripts/set_webhook.js https://futureair-erp.vercel.app/api/webhook
   ```
6. مبروك! البوت يعمل الآن بنظام الـ Webhook بنجاح كـ Serverless بالكامل.
